# The Unleash Tribe Check-in

A modern daily accountability platform for The Unleash Tribe.

## Project Version

MVP 1

## Purpose

Replace manual WhatsApp daily accountability check-ins with a secure web application.

## Technology Stack

Frontend:
- HTML5
- CSS3
- JavaScript ES6 Modules

Backend:
- Supabase

Database:
- PostgreSQL

Hosting:
- Vercel

Version Control:
- Git and GitHub
